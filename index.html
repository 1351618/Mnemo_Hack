Инструкция

Это только интерфейс. Все твои данные хранятся в твоём Google документе.

  1. Создай Google таблицу
  2. В первый лист вставь шаблон: 
    2	19.05.26	комент	TRUE	мамон	TRUE	0 000	TRUE	я	TRUE	i	TRUE	εγώ
-	-	комент	TRUE	манеж	TRUE	0 001	FALSE	мы	TRUE	we	FALSE	εμείς
  3. Открой script.google.com

    https://script.google.com/macros/s/AKfycbzT1P1hnL-7uaiwJ0Eu4-4RCPiqTLdNCGjZxiF-8d6aoH9nXqLlto_wIoEK-u5pxycg/exec

  4. Вставь туда скрипт
    → Развернуть
    → Новое развертывание
    → Выберите тип: Веб-приложение
    → У кого есть доступ: Все
    → Начать развертывание
    → Скопируйте нижнюю ссылку и вставьте сюда:
  5. Скопируй полученную ссылку и вставь в поле выше
