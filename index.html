Это только интерфейс. Все твои данные хранятся в твоём Google документе.

  1. Создай Google таблицу
  2. В первый лист вставь шаблон:
    комент | TRUE | КодЦбк | TRUE | 0 000 | TRUE | я | TRUE | i | TRUE | εγώ
  3. Открой script.google.com

    https://script.google.com/macros/s/AKfycbyP3VJkexE3XRfPBPo74H0Wmps--S-TF7qddEkjIi4FmYeIuIq7ZPrT2b3ovlEkY9z6/exec

  4. Вставь туда скрипт (ниже) → Сохрани → Деплой → Веб-приложение → доступ: Все
  5. Скопируй полученную ссылку и вставь в поле выше
